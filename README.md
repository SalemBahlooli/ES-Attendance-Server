# ES Attendance Server

سيرفر حضور وانصراف يستقبل البصمات مباشرة من جهاز **ZKTeco uFace 800** عبر خاصية Cloud Server (ADMS)، ويحفظها في PostgreSQL، ويعرضها في لوحة ويب بالإنجليزي.

## التشغيل على Railway

1. في المشروع على Railway: **New ← GitHub Repository** واختر هذا المستودع.
2. إذا ما عندك قاعدة بيانات: **New ← Database ← PostgreSQL**.
3. في خدمة السيرفر ← **Variables** أضف:

   | المتغير | القيمة |
   |---|---|
   | `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
   | `ADMIN_PASSWORD` | كلمة مرور حساب `admin` (المالك) |
   | `SESSION_SECRET` | نص عشوائي طويل |
   | `WORK_START` / `WORK_END` | دوام الوردية الافتراضية أول تشغيل، مثلاً `08:00` و `16:00` (اختياري، وتقدر تعدلها بعدين من اللوحة) |

4. **Settings ← Networking**:
   - **Generate Domain**: هذا رابط اللوحة اللي تفتحه من المتصفح.
   - **TCP Proxy** على المنفذ `8080` (أو قيمة `PORT`): هذا العنوان اللي تكتبه في الجهاز.

## التشغيل على جهازك بـ Docker

تحتاج Docker Desktop (أو Docker على لينكس). بعدها من مجلد المشروع:

```
docker compose up -d --build
```

- افتح اللوحة على `http://localhost:8090`، وادخل بـ `admin` / `admin123`.
- لتغيير كلمة المرور، سوّ ملف اسمه `.env` جنب `docker-compose.yml` فيه:

  ```
  ADMIN_PASSWORD=كلمة-مرور-قوية
  SESSION_SECRET=نص-عشوائي-طويل
  APP_PORT=8090
  ```

  `APP_PORT` هو المنفذ على جهازك. لو 8090 مستخدم في برنامج ثاني غيّره لأي رقم فاضي، واستخدم نفس الرقم في جهاز البصمة.

  بعدها شغّل `docker compose up -d` مرة ثانية.
- قاعدة البيانات PostgreSQL تشتغل معه في نفس الـ compose، وبياناتها محفوظة في volume اسمه `pgdata`. إيقاف التشغيل ما يمسحها.
- أوامر مفيدة:
  - `docker compose logs -f app`: يعرض سجل السيرفر.
  - `docker compose down`: يوقف التشغيل والبيانات باقية.
  - `docker compose down -v`: يوقف ويمسح كل البيانات.

**ربط جهاز البصمة بالسيرفر المحلي:**
- في الجهاز: Server Address هو IP الكمبيوتر في الشبكة (مثل `192.168.1.50`)، وServer Port هو `8090`، وHTTPS مطفي.
- لازم الجهاز والكمبيوتر يكونون على نفس الشبكة.
- لازم جدار الحماية في الكمبيوتر يسمح بالمنفذ 8090.

## إعداد الجهاز

**Menu ← COMM ← Cloud Server Setting**

- Enable Domain Name: **ON**
- Server Address: عنوان الـ TCP Proxy بدون المنفذ (مثل `xxx.proxy.rlwy.net`)
- Server Port: منفذ الـ TCP Proxy (مثل `12345`)
- HTTPS: **OFF**
- Proxy Server: **OFF**

بعد الحفظ أعد تشغيل الجهاز. خلال دقيقة يظهر في تبويب **الأجهزة** في اللوحة.

## ملاحظات

- أسماء الموظفين: اضغط "سحب أسماء الموظفين من الجهاز" في تبويب الأجهزة، أو اكتبها يدوياً في تبويب الموظفين.
- البصمات القديمة المخزنة في الجهاز: اضغط "إعادة سحب كل البصمات". البصمات المكررة تُتجاهل تلقائياً.

## ميزات اللوحة

- **نظرة عامة (Overview)**: تعرض أي فترة، مو بس يوم بيوم:
  - فترات جاهزة: اليوم، أمس، هذا الأسبوع، آخر 7 أيام، هذا الشهر، الشهر الماضي، آخر 30 يوم، أو أي تاريخين. الأسهم ‹ › تنقلك للفترة اللي قبل أو بعد.
  - تقويم يلوّن الأيام اللي فيها بصمات (كل ما كان أغمق كان عدد الموظفين أكثر). اضغط اليوم يفتح، أو اختر "Pick a range" واضغط أول يوم وآخر يوم.
  - تصفية حسب القسم والموظف.
  - رسوم: الحضور اليومي حسب الحالة (حاضر، متأخر، إجازة، غائب)، وخط زمني لليوم الواحد، وأوقات الوصول، والبصمات حسب الساعة، وخريطة حضور (موظف × يوم).
  - كل الحسابات من نفس قواعد التقرير: الوردية ومهلة التأخير والعطل والإجازات.
- **الحضور اليومي**: حاضر ومتأخر وغائب وإجازة ولم يبصم بعد، مع دقائق التأخير والخروج المبكر وساعات العمل، وتصفية حسب القسم.
- **التقرير**: ملخص لكل موظف خلال الشهر أو أي فترة (أيام العمل والحضور والغياب والإجازات والتأخير والخروج المبكر وساعات العمل)، واضغط على الموظف تشوف تفاصيل أيامه.
- **تصدير Excel** (.xlsx): ثلاث صفحات: الملخص، والتفصيلي اليومي، والبصمات.
- **التايم شيت**: من صفحة التقرير، زر "التايم شيت" يطلّع ملف بنفس تصميم تايم شيت الشركة. الفترة من 16 للشهر اللي قبل الشهر المختار إلى 15 منه، ولكل موظف صفين:
  - **صف Att.:** رمز لكل يوم:
    - D: حاضر
    - A: غائب
    - F: عطلة أسبوعية أو رسمية
    - V: إجازة سنوية
    - SL: إجازة مرضية
    - U: إجازة بدون راتب
    - E: إجازة اضطرارية
    - LB: مهمة عمل
  - **صف OT:** فاضي، يتعبى يدوي.
  - **Delay (Hours):** مجموع ساعات التأخير.
  - **Total Days:** معادلة Excel تتحدث تلقائياً.
- **الإجازات والعطل**: إجازات الموظفين (سنوية، مرضية...) والعطل الرسمية، وأيامها ما تنحسب غياب.
- **الورديات والأقسام**: لكل وردية وقت دخول وخروج ومهلة تأخير وأيام عطلة أسبوعية. ترتيب الوردية اللي تنطبق على الموظف: وردية الموظف، ثم وردية قسمه، ثم الوردية الافتراضية.
- **الموظفين**: القسم والوردية وتاريخ المباشرة، وإيقاف الموظف اللي ترك العمل.

ملاحظات الحساب:
- يوم الوردية يبدأ قبل وقت الدوام بأربع ساعات ويستمر 24 ساعة، فالورديات الليلية تنحسب صح.
- أول بصمة هي الدخول وآخر بصمة هي الخروج. بصمتين بينهم أقل من 5 دقائق تنحسب بصمة وحدة.
- إذا ما حددت تاريخ المباشرة للموظف، يبدأ الحساب من أول بصمة له.

## تعديل البصمات

من صفحة **Daily attendance** أو من صفحة الموظف (Employees ← View punches)، زر "Edit punches" أو "Add punch" لكل يوم:
- **إضافة** بصمة ناقصة (مثلاً نسي يبصم دخول أو خروج).
- **تعديل** وقت بصمة.
- **حذف** بصمة (مثلاً بصمة مكررة بالغلط).

تحتاج صلاحية "Add, edit and delete punches". كل تعديل ينسجل في سجل العمليات مع اسم المستخدم والسبب. البصمة المحذوفة أو المعدلة ما تنمسح فعلياً، تنحفظ في الخلفية عشان لو الجهاز أرسلها مرة ثانية ما ترجع. البصمات اليدوية تظهر بإطار متقطع في جدول الموظف، وبعلامة "Manual" في سجل البصمات.

## استيراد البصمات (USB، ملف، الشبكة)

من صفحة **Import data** (تحتاج صلاحية "Import punches from USB, files or the LAN"):

- **USB أو ملف**: في الجهاز **Menu ← PenDrive Mng (أو USB Manager) ← Download AttLog**، وبعدها اختر الملف (`1_attlog.dat` أو `<serial>_attlog.dat`). ملفات CSV وTXT تشتغل كمان إذا فيها عمود رقم الموظف وعمود التاريخ والوقت. قبل الحفظ تطلع معاينة فيها عدد البصمات وكم وحدة جديدة.
- **من الجهاز عبر الشبكة**: اكتب IP الجهاز والمنفذ `4370`، واضغط "Test connection" ثم "Pull punches now". هذا يشتغل لما يكون السيرفر على نفس شبكة الجهاز، مثل Docker على كمبيوتر في المكتب. بعد أول سحب يطلع زر "Pull over LAN" في صفحة الأجهزة.
- **البرنامج الوسيط (لو السيرفر على Railway)**: Railway ما يقدر يوصل لشبكة المكتب. شغّل هذا على أي كمبيوتر في نفس شبكة الجهاز (بعد تثبيت Node.js وتشغيل `npm install` مرة وحدة):

  ```
  node tools/lan-bridge.js --device 192.168.1.201 --server https://رابط-اللوحة --user admin --password كلمة-المرور --every 5
  ```

  يقرأ الجهاز كل 5 دقايق ويرسل البصمات الجديدة. المستخدم لازم يكون عنده صلاحية الاستيراد.

البصمة المكررة (نفس الموظف بنفس الثانية) ما تنحفظ مرتين، مهما كان مصدرها. وكل عملية استيراد تنسجل في سجل العمليات وسجل الاستيراد.

## المستخدمين والصلاحيات

- **حساب المالك:** اسم المستخدم `admin` وكلمة المرور قيمة `ADMIN_PASSWORD`. له كل الصلاحيات دائماً، فما يمكن تنقفل اللوحة عليك.
- من صفحة **المستخدمين والصلاحيات** تسوي حسابات لموظفيك، وتعطي كل حساب **دور**. الدور هو مجموعة صلاحيات تختارها: عرض، تعديل، تصدير، إدارة الأجهزة وغيرها.
- فيه ثلاثة أدوار جاهزة: مدير النظام (كل الصلاحيات)، ومشرف، ومشاهد. وتقدر تعدلها أو تضيف أدوار جديدة.
- **سجل العمليات** يحفظ مين سوّى وش: تسجيل الدخول، وتعديل الموظفين، والإجازات، والإعدادات، والحسابات.
- إيقاف الحساب أو تغيير كلمة مروره يطلّع صاحبه من اللوحة فوراً.
- بعد 10 محاولات دخول خاطئة من نفس الجهاز، يتقفل الدخول 15 دقيقة.
