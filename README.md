# ES Attendance

نظام حضور وانصراف يستقبل البصمات مباشرة من جهاز **ZKTeco uFace 800** عبر خاصية Cloud Server (ADMS)، ويحسب الحضور والتأخير والغياب، ويصدّر Excel والتايم شيت.

هذه النسخة مبنية على **[Laravel Template](https://github.com/SalemBahlooli/Laravel-Template)**، فيها كل ميزات النسخة الأولى (Node.js) ومعها أساسات القالب: تسجيل الدخول مع التحقق بخطوتين، المستخدمون، المجموعات وشجرة الصلاحيات، الإعدادات من المتصفح، الإشعارات، سجل النشاط وسجل الدخول، النسخ الاحتياطي، واجهة API، والعربية والإنجليزية.

---

## التشغيل على جهازك بـ Docker

تحتاج Docker Desktop. من مجلد المشروع:

</div>

```bash
docker compose up -d --build
```

<div dir="rtl">

- اللوحة على `http://localhost:8090`. الدخول بـ `admin@example.com` / `password` (من `ADMIN_EMAIL` و`ADMIN_PASSWORD` في `.env`). غيّر كلمة المرور بعد أول دخول.
- قاعدة البيانات MySQL تعمل معه في نفس الـ compose وبياناتها في volume، وإيقاف التشغيل لا يمسحها.
- البريد الذي يرسله النظام يظهر في Mailpit على `http://localhost:8026`.
- بيانات تجريبية (أقسام وموظفين وبصمات شهرين) لتجربة الصفحات:

</div>

```bash
docker compose exec app php artisan db:seed --class=AttendanceDemoSeeder
```

<div dir="rtl">

لتغيير المنفذ اكتب في ملف `.env` مثلاً `APP_PORT=8095`، واستخدم نفس الرقم في جهاز البصمة.

## التشغيل على Railway

ملف `railway.json` جاهز. أضف قاعدة بيانات MySQL أو PostgreSQL، ثم المتغيرات: `APP_KEY` (من `php artisan key:generate --show`)، و`APP_URL`، و`DB_*`، و`ADMIN_EMAIL` و`ADMIN_PASSWORD` لأول حساب. التفاصيل في [docs/deployment.md](docs/deployment.md).

لربط الجهاز بسيرفر Railway فعّل **TCP Proxy** على منفذ التطبيق، واكتب عنوانه في الجهاز.

## إعداد الجهاز

**Menu ← COMM ← Cloud Server Setting**

- Enable Domain Name: **ON** (لو العنوان اسم نطاق)
- Server Address: عنوان السيرفر بدون المنفذ (IP الكمبيوتر في الشبكة لو Docker محلي، أو عنوان الـ TCP Proxy)
- Server Port: منفذ السيرفر (`8090` محلياً)
- HTTPS: **OFF**، Proxy Server: **OFF**

أعد تشغيل الجهاز، فيظهر خلال دقيقة في صفحة **الأجهزة**. لازم الجهاز والكمبيوتر على نفس الشبكة لو التشغيل محلي، وجدار الحماية يسمح بالمنفذ.

لو تبي تقصر الإرسال على أجهزتك فقط: **الإعدادات ← الحضور ← الأرقام التسلسلية للأجهزة المسموح بها**.

## الصفحات

| الصفحة | المحتوى |
|---|---|
| **نظرة عامة** | أي فترة (اليوم، أمس، هذا الأسبوع، آخر 7 أيام، هذا الشهر، الشهر الماضي، آخر 30 يوم أو أي تاريخين)، تقويم يلوّن الأيام حسب عدد من بصم، رسوم الحضور اليومي حسب الحالة، الخط الزمني لليوم الواحد، أوقات الوصول، البصمات حسب الساعة، خريطة حضور (موظف × يوم)، وجدول حسب الموظف أو يوماً بيوم |
| **الحضور اليومي** | حاضر ومتأخر وغائب وإجازة ولم يبصم بعد، مع التأخير والخروج المبكر ومدة العمل وتصفية حسب القسم، وزر تعديل البصمات لكل موظف |
| **التقرير** | ملخص لكل موظف لشهر أو أي فترة، وتفاصيل أيامه، وتصدير Excel (الملخص، التفصيلي، البصمات)، والتايم شيت، والإرسال لفرع آخر |
| **الإجازات والعطل** | إجازات الموظفين (سنوية، مرضية، اضطرارية، بدون راتب، مهمة عمل، أخرى) والعطل الرسمية، وأيامها لا تُحسب غياباً |
| **الموظفون** | القسم والوردية وتاريخ المباشرة والإيقاف، وصفحة لكل موظف بأيامه وبصماته وتصدير CSV |
| **سجل البصمات** | كل بصمة كما سُجّلت، والبصمات اليدوية معلّمة |
| **الورديات والأقسام** | لكل وردية دخول وخروج وسماحية تأخير وخروج مبكر وأيام عطلة أسبوعية. ترتيب الوردية: وردية الموظف، ثم وردية قسمه، ثم الافتراضية |
| **الأجهزة** | آخر اتصال وعدد البصمات، وإعادة التسمية، وأوامر: سحب أسماء الموظفين، وإعادة سحب كل البصمات |
| **الاستيراد والتصدير** | ملف USB (`attlog.dat`) أو CSV/TXT مع معاينة قبل الحفظ، والسحب المباشر من الجهاز عبر الشبكة (منفذ 4370)، وملف من فرع آخر، وسجل الاستيراد |

## قواعد الحساب

- يوم الوردية يبدأ قبل وقت الدوام بأربع ساعات ويستمر 24 ساعة، فالورديات الليلية تنحسب على يوم بدايتها.
- أول بصمة دخول وآخر بصمة خروج. بصمتان بينهما أقل من 5 دقائق تُحسبان بصمة واحدة.
- التأخير يُحسب بكامل الدقائق إذا تجاوز السماحية. البصمة في يوم عطلة تُحسب "عمل في يوم راحة".
- بدون تاريخ مباشرة، يبدأ الحساب من أول بصمة للموظف. الموظف غير النشط لا يدخل في الحساب.
- أوقات البصمات تُحفظ بساعة الجهاز كما هي، والمنطقة الزمنية للجهاز هي منطقة النظام في **الإعدادات ← عام**.

## التايم شيت

من صفحة التقرير. الفترة من 16 الشهر السابق إلى 15 من الشهر المختار، ولكل موظف صفان:
- **Att.:** رمز لكل يوم: D حاضر، A غائب، F عطلة أسبوعية أو رسمية، V سنوية، SL مرضية، U بدون راتب، E اضطرارية أو أخرى، LB مهمة عمل.
- **OT:** فارغ ويُعبّأ يدوياً. وفيه Delay (Hours) مجموع ساعات التأخير، وTotal Days معادلة Excel.

## تعديل البصمات

من الحضور اليومي أو صفحة الموظف أو سجل البصمات، زر "تعديل البصمات": إضافة بصمة ناقصة، أو تعديل وقت، أو حذف بصمة. كل تعديل يُحفظ في **سجل النشاط** مع السبب، والبصمة المحذوفة أو المعدّلة تبقى في الخلفية حتى لا يعيدها الجهاز.

## مشاركة الحضور مع فرع ثاني

1. **عندك:** التقرير ← **إرسال إلى فرع آخر** (أو صفحة الاستيراد والتصدير). اكتب اسم فرعك والفترة والقسم، ونزّل الملف `Attendance_<الفرع>_<من>_<إلى>.json`.
2. أرسله للفرع الثاني بأي طريقة.
3. **عنده:** الاستيراد والتصدير ← **من USB أو ملف**، فتظهر معاينة (الموظفون، البصمات الجديدة، المُزالة، الإجازات) قبل **استيراد**.

الملف فيه آخر نسخة من البيانات فقط. ملف أحدث لنفس الفترة يجعل ما وصل من فرعك مطابقاً له، وبصمات أجهزته وتعديلاته هو لا تتأثر. العطل الرسمية لا تنتقل.

## السيرفر في السحابة؟ البرنامج الوسيط

السيرفر السحابي لا يصل لشبكة المكتب. على أي كمبيوتر في نفس شبكة الجهاز (بعد تثبيت Node.js):

</div>

```bash
cd tools/lan-bridge && npm install
node lan-bridge.js --device 192.168.1.201 --server https://رابط-اللوحة --token رمز-API --every 5
```

<div dir="rtl">

الرمز من **حسابي ← رموز API**، وصاحبه يحتاج صلاحية "استيراد البصمات من USB أو الملفات أو الشبكة" وصلاحية "إنشاء رموز API".

## المستخدمون والصلاحيات

من **المجموعات والصلاحيات** في القالب. صلاحيات الحضور تحت تبويب **Modules**: الحضور اليومي، التقارير والتصدير، سجل البصمات وتعديلها، الإجازات والعطل، الموظفون، الورديات والأقسام، الأجهزة، الاستيراد. فيه مجموعتان جاهزتان: **Supervisors** و**Viewers**، والمدير الأول في **Administrators**.
