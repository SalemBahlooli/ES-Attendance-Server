# ES Attendance Server

سيرفر حضور وانصراف يستقبل البصمات مباشرة من جهاز **ZKTeco uFace 800** عبر خاصية Cloud Server (ADMS)، ويحفظها في PostgreSQL، ويعرضها في لوحة ويب بالعربي.

## التشغيل على Railway

1. في المشروع على Railway: **New ← GitHub Repository** واختر هذا المستودع.
2. إذا ما عندك قاعدة بيانات: **New ← Database ← PostgreSQL**.
3. في خدمة السيرفر ← **Variables** أضف:

   | المتغير | القيمة |
   |---|---|
   | `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
   | `ADMIN_PASSWORD` | كلمة مرور اللوحة |
   | `SESSION_SECRET` | نص عشوائي طويل |
   | `WORK_START` / `WORK_END` | دوام الوردية الافتراضية أول تشغيل، مثلاً `08:00` و `16:00` (اختياري، وتقدر تعدلها بعدين من اللوحة) |

4. **Settings ← Networking**:
   - **Generate Domain**: هذا رابط اللوحة اللي تفتحه من المتصفح.
   - **TCP Proxy** على المنفذ `8080` (أو قيمة `PORT`): هذا العنوان اللي تكتبه في الجهاز.

## إعداد الجهاز

**Menu ← COMM ← Cloud Server Setting**

- Enable Domain Name: **ON**
- Server Address: عنوان الـ TCP Proxy بدون المنفذ (مثل `xxx.proxy.rlwy.net`)
- Server Port: منفذ الـ TCP Proxy (مثل `12345`)
- HTTPS: **OFF**
- Proxy Server: **OFF**

بعد الحفظ أعد تشغيل الجهاز. خلال دقيقة يظهر في تبويب **الأجهزة** في اللوحة.

## ملاحظات

- أسماء الموظفين: اضغط "سحب أسماء الموظفين من الجهاز" في تبويب الأجهزة، أو اكتبها يدوياً في تبويب الموظفين.
- البصمات القديمة المخزنة في الجهاز: اضغط "إعادة سحب كل البصمات". البصمات المكررة تُتجاهل تلقائياً.

## ميزات اللوحة

- **الحضور اليومي**: حاضر ومتأخر وغائب وإجازة ولم يبصم بعد، مع دقائق التأخير والخروج المبكر وساعات العمل، وتصفية حسب القسم.
- **التقرير**: ملخص لكل موظف خلال الشهر أو أي فترة (أيام العمل والحضور والغياب والإجازات والتأخير والخروج المبكر وساعات العمل)، واضغط على الموظف تشوف تفاصيل أيامه.
- **تصدير Excel** (.xlsx): ثلاث صفحات: الملخص، والتفصيلي اليومي، والبصمات.
- **الإجازات والعطل**: إجازات الموظفين (سنوية، مرضية...) والعطل الرسمية، وأيامها ما تنحسب غياب.
- **الورديات والأقسام**: لكل وردية وقت دخول وخروج ومهلة تأخير وأيام عطلة أسبوعية. ترتيب الوردية اللي تنطبق على الموظف: وردية الموظف، ثم وردية قسمه، ثم الوردية الافتراضية.
- **الموظفين**: القسم والوردية وتاريخ المباشرة، وإيقاف الموظف اللي ترك العمل.

ملاحظات الحساب:
- يوم الوردية يبدأ قبل وقت الدوام بأربع ساعات ويستمر 24 ساعة، فالورديات الليلية تنحسب صح.
- أول بصمة هي الدخول وآخر بصمة هي الخروج. بصمتين بينهم أقل من 5 دقائق تنحسب بصمة وحدة.
- إذا ما حددت تاريخ المباشرة للموظف، يبدأ الحساب من أول بصمة له.
