From USB or a file

  1. On the device: Menu → PenDrive Mng (or USB Manager) → Download AttLog.
  2. Plug the USB stick into this computer and choose the file, usually 1_attlog.dat or <serial>_attlog.dat.
  3. CSV or TXT files also work, for example an export from ZKTeco software saved as CSV. They need an employee ID column and a date/time column.

From the device over LAN

Reads all punches and employee names straight from the device on port 4370. This only works when the server can reach the device's IP address (server running on the same network).

Server in the cloud? Use the LAN bridge
