From USB or a file

  1. On the device: Menu → PenDrive Mng (or USB Manager) → Download AttLog.
  2. Plug the USB stick into this computer and choose the file, usually 1_attlog.dat or <serial>_attlog.dat.
  3. CSV or TXT files also work, for example an export from ZKTeco software saved as CSV. They need an employee ID column and a date/time column.

From the device over the LAN

Reads all punches and employee names straight from the device on port 4370. This works when this server runs on the same network as the device, for example in Docker on an office PC.

Server in the cloud? Use the LAN bridge

Railway cannot reach your office network. Run this small program on any office PC on the same network as the device. It reads the device over the LAN and sends new punches here.

  1. Install Node.js on the PC and download this repository.
  2. In the repository folder, open Command Prompt and run npm install once.
